# What's new in Lichen

## New apps
- Timer: a countdown that notifies you when it ends, a stopwatch and a world clock.
- Calculator: decimal, hex and binary, bit operations, and conversions such as dBm to milliwatt.
- Weather: temperature, humidity, pressure and air quality with a history graph. It can log to the SD card.
- Notes: notes and to dos, saved as plain text files on the SD card.
- QR code: show any text or a Wi-Fi join code as a QR code. Contacts and channels have a Show as QR option too.
- LoRa spectrum: signal strength across the 868 MHz band and the noise on the MeshCore channel. Receive only; MeshCore pauses while it is open.
- The Release notes app is now called What's new.

## MeshCore
- Radio health: noise floor, last signal, send and receive airtime, packet counts and lost packets.
- Air log: a live list of the packets the badge hears. Only the headers are kept, never the message text.
- Signal page per contact: graphs of signal strength and signal to noise, hops and the last path.
- Flood scope: keep flood messages within a region. The default is None (everywhere).
- Contact radar in MeshCore > Settings > Contact radar: contacts that share a position, by distance and direction from yours.
- Path hash size is its own setting, and routes stored with the wrong size are forgotten.

## Wi-Fi and network
- Up to 5 saved Wi-Fi networks. The badge joins the strongest one it knows, and each has its own Forget.
- Wi-Fi analyser in Settings > Wi-Fi: how busy each channel is, and a signal meter to find an access point.
- The badge can be reached on the network as lichen-xxxx.local. Settings shows its name.
- Wi-Fi power saving is off by default, so the badge answers faster.

## Settings and care
- Settings > Backup: save your settings to the SD card and load them back. Passwords and keys are never saved.
- Crash records can be copied to the SD card or read over Wi-Fi.
- A vibration motor buzz for notifications, with a strength setting.
- A Console app for developers: run badge commands from the keyboard.
- Faster memory (PSRAM at 120 MHz), tried at start-up with a safe fallback.

## Screens
- Every screen follows one style: clear headings, plain values, a hint for the keys and a message when a list is empty.
- Long names and texts no longer run off the screen.
- The file viewer wraps at words and pages through long files.
- A screen that is already open is never opened a second time.
