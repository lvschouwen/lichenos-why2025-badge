# What an SD app may resolve besides the gate's functions (#519); read by tools/gen_export_table.py. `name` exports the
# function of that name, `name = target` exports the OS's own function target under the app's name. Anything that
# layers.conf forbids apps (`forbid L6`) needs a mapping or is refused by the generator. Adding a line is an API change
# (tools/export_table.txt, LICHEN_API_VERSION minor).
#
# Not here on purpose (the DOOM glue, #525, avoids them with a force-included shim header, so a ported program needs no change):
#   printf puts putchar fprintf fputs vfprintf  a user-controlled format is a door, and they need stdout, which is reached
#                                               through __getreent; snprintf and vsnprintf only write to a buffer
#   system                                      runs another program
#   _ctype_ __getreent __errno                  newlib's per-task state: the app would read the OS's reent, and the PSRAM
#                                               image has no business with it (isalpha and friends are functions above)
#   esp_rom_printf, socket calls                the gate's caps are the way
#   getc putc feof ferror fgets and the rest of stdio: the file shims below are fread/fwrite/fseek/ftell only, on a handle
#                                               of the OS's own (a slot of export_file.c's book, never a real FILE), so the
#                                               getc/putc macros, which reach into the FILE struct, are not supported.
# Files (#533): fopen fclose fread fwrite fseek ftell fflush remove rename mkdir work on the app's own SD directory only
# (lichen_fs_sd_dir; a relative path, or an absolute one under it; no "..", other drive or backslash), at most 4 open files,
# the SD lock per call. exit ends the app through the normal unload and never returns (sd_app_loader.c).
# An SD app may not call vTaskDelete(NULL) (the task book wants the function to return); it returns, or calls exit.
# exit() from an LVGL callback or hook aborts the badge (it cannot end that task), counted against the app; vTaskDelay returns
# early after a second. The lv_* below are LVGL-task-only, like the originals: an app task wraps every call in lichen_ui_call (which takes the LVGL
# lock and runs it on the LVGL task); an app that calls one from its own task races LVGL (#525, #526 rely on this).
# The app's SD folder (/sd/lichen/apps/<id>) also holds its own manifest and ELF, and the file calls can overwrite them.
# Adding a line is an API change (tools/export_table.txt, LICHEN_API_VERSION minor).

# Stack protector (#586): an app built with -fstack-protector reads the firmware's own canary and panics through the
# firmware's fail handler, so a smash in app code is caught like one in the OS. __stack_chk_guard is data; the table only
# holds an address, which is all a GOT slot needs.

__stack_chk_fail
