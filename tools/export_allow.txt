# What an SD app may resolve besides the gate's functions (#519); read by tools/gen_export_table.py. `name` exports the
# function of that name, `name = target` exports the OS's own function target under the app's name. Anything that
# layers.conf forbids apps (`forbid L6`) needs a mapping or is refused by the generator. Adding a line is an API change
# (tools/export_table.txt, LICHEN_API_VERSION minor).
#
# Not here on purpose: printf and friends (a user-controlled format is a door; snprintf and vsnprintf only write to a
# buffer), esp_rom_printf, file and socket calls (the gate's lichen_fs and its caps are the way), abort and exit.
