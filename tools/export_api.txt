# The app-facing API an SD app may resolve (#519, Lucas's decision of 2026-11-23: opt-in, a curated list). Read by
# tools/gen_export_table.py, together with tools/export_allow.txt (libc, libm, lv_*). What docs/app-api.md documents for
# apps, and nothing else: a function in a lichen_api header is the OS's until a line here names it.
#   header H.h   every function H.h declares, minus the `deny` lines below it
#   func NAME    one function (of a header that is not listed whole)
#   deny NAME    a function of a listed header that stays the OS's
# A header, func or deny line that matches nothing fails the generator. layers.conf's `forbid L6` still applies on top.
# Adding a line is an API change (tools/export_table.txt, LICHEN_API_VERSION minor).
#
# Left out on purpose: fw_console.h (a command registered by an app that is later unloaded would dangle; console_reply
# and system_restart_* come with the capabilities that guard them, #523), the crash log, bench_scope.h, key_cause.h,
# tile_order.h, test_card*.h, qr_screen.h (OS and built-in app internals), every lichen_sys_* and *_bind* hook,
# app_ctx.h, notify_os.h, settings_store.h, mem_book.h, task_book.h, update_mode.h.
